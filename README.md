# FSYSTEMS

Landing en [Astro](https://astro.build) + CSS puro (sin frameworks de UI).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
```

Estructura: `src/pages/index.astro` arma la página con los componentes de `src/components/` (una sección por archivo). Colores y tipografía en `src/styles/global.css` (`:root`).
